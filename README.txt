DEV BITE — ATIVIDADE DE HTML5 E CSS3

Como abrir:
1. Entre na pasta "dist".
2. Abra o arquivo "index.html" no navegador.
3. Use o menu para navegar entre Cardápio, Meu Carrinho e Área Restrita.

Arquivos principais:
- index.html: cardápio com seis produtos.
- checkout.html: carrinho, total e formulário de entrega/pagamento.
- admin.html: painel, cadastro de produto e pedidos recentes.
- style.css: toda a estilização responsiva.
- assets/: ilustrações locais dos produtos.

O projeto é apenas visual, conforme solicitado. Os formulários, botões e controles
possuem IDs únicos e estão preparados para receber JavaScript em uma próxima etapa.
